# Screenshot gallery

Five full-frame views from Infinite 0.52.1, rendered at 1920 × 1080 using the production Hyperion renderer on Metal. The HUD is hidden, as it is when toggled off with Tab during play. Images retain their original framing and colours and are encoded as JPEG at quality 88 for the repository landing page.

| Image | Scene |
|---|---|
| [Ringed gas giant](ringed-gas-giant.jpg) | A cold giant and nearby world in the default galaxy's first system. |
| [Spiral galaxy](spiral-galaxy.jpg) | A closer view of the default galaxy's stellar disc and spiral structure. |
| [Ice giant](ice-giant.jpg) | A cyan outer world, rings and the surrounding stellar background. |
| [Volcanic world](volcanic-world.jpg) | A generated solid planet with a surface temperature around 1101 K. |
| [Quartz atomic lattice](quartz-lattice.jpg) | A close view of the actual silicon/oxygen structure within a quartz grain. |

The planetary shots use the native planet-diversity fixture. Galaxy and atomic shots use the same production Renderer, Navigation and RegionCache with fixed camera views. Captures use universe seed `5282236693612155973` and visual time 12 seconds, after generation and LOD transitions settle.

[Capture metadata](captures.json) records addresses, camera states, source revision, dimensions and hashes. Universe generation, geometry, shaders, controls and existing saves are unchanged by this gallery.
